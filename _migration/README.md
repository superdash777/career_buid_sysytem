# План загрузки в чистовой репозиторий

**Целевой репо:** https://github.com/superdash7/career_copilot_

Загружайте фазы **строго по порядку**.

| # | Папка | Что загружаем | Действие |
|---|-------|---------------|----------|
| 1 | `01_backend/` | Python-модули, данные, конфиги | Upload files |
| 2 | `02_frontend/` | React/TypeScript фронтенд | Upload files |
| 3 | `03_docs_devops/` | Документация, тесты, Docker | Upload files |
| 4 | `04_cleanup/` | Удаление старых файлов | Delete files |

Инструкции для каждой фазы — в `README_UPLOAD.md` внутри папки.

## Важно

- Каждая фаза = один коммит в чистовом репо
- Между фазами можно делать паузы (для естественности истории)
- Не загружайте `package-lock.json` — он слишком большой для GitHub UI
- Папку `career_buid_sysytem-main/` можно оставить как архив MVP
