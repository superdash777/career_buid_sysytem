## Слайд 3. Пайплайн обработки данных (gap-анализ)

| № | Этап | Описание | Детализация |
|---|---|---|---|
| 1 | **Нормализация навыков** | Произвольный ввод пользователя приводится к каноническим названиям | 3 уровня: словарь синонимов → лемматизация (pymorphy3 / NLTK) → семантический поиск |
| 2 | **Загрузка требований роли** | Система определяет, какие навыки и на каком уровне нужны для целевой роли | Навыки: шкала 1–3 (Basic / Proficiency / Advanced); Параметры роли: шкала 1–5 (Junior → Expert) |
| 3 | **Семантический мэтчинг** | Навыки пользователя сопоставляются с требованиями роли с учётом смысловой близости | Эмбеддинги multilingual-e5-large-instruct (1024d), косинусное сходство, порог 0.72 |
| 4 | **Gap-анализ** | Для каждого требования считается разрыв: насколько текущий уровень отличается от нужного | Δ = required − current; классификация: критический (Δ≥2), умеренный (Δ=1), освоен (Δ≤0) |
| 5 | **Генерация плана** | По выбранным пользователем навыкам формируется персонализированный план развития | GPT-4o (temperature 0.3) + контекст из JSON-базы → структурированный вывод: задачи / взаимодействие / обучение |

## Дополнительные детали для вопросов комиссии

### Архитектурные решения

- **Монолитный контейнер** — FastAPI раздаёт и API, и собранный SPA из одного образа
- **Гибридный поиск** — dense (E5) + lexical (RapidFuzz Jaccard/token_sort) + RRF-фьюжн
- **Двойная модель эмбеддингов** — E5-large-instruct для точного маппинга навыков, MiniLM для быстрого RAG
- **Без Qdrant SDK** — прямое взаимодействие через REST для минимизации образа
- **Graceful degradation** — приложение работает без Qdrant (теряя семантические подсказки)

### Модели OpenAI

| Модель | Temperature | Назначение |
|---|---|---|
| gpt-4o | 0.0–0.1 | Извлечение навыков из резюме (JSON mode) |
| gpt-4o-mini | 0.0 | Пакетный реранкинг, классификация навыков |
| gpt-4o | 0.2–0.3 | Генерация плана развития 70/20/10 |

### Pipeline обработки резюме

```
PDF (pypdf) → текст → GPT-4o extraction → E5 hybrid retrieval
  → GPT-4o-mini batch rerank → GPT-4o-mini level assessment → нормализованные навыки
```
